# Калькулятор Индекса массы тела

Учебный CLI-проект на Go для расчета индекса массы тела (ИМТ).

Проект создан в процессе изучения Go и Git. В нем отрабатываются базовые темы: ввод данных из консоли, обработка ошибок, простая бизнес-логика, тестирование и работа с ветками.

## Что умеет программа

- Запрашивает вес пользователя в килограммах.
- Запрашивает рост пользователя в сантиметрах.
- Рассчитывает индекс массы тела по формуле:

```text
ИМТ = вес / (рост * рост)
```

- Показывает результат расчета.
- Выводит категорию ИМТ:
  - недовес;
  - нормальная масса тела;
  - избыточный вес;
  - ожирение первой, второй или третьей степени.
- Продолжает работу после некорректного ввода.

## Технологии

- Go

## Как запустить

Склонируйте репозиторий:

```bash
git clone <url-репозитория>
```

Перейдите в папку проекта:

```bash
cd <название-проекта>
```

Запустите программу:

```bash
go run .
```

## Как запустить тесты

```bash
go test ./...
```

Эта команда запускает все тесты во всех пакетах проекта.
